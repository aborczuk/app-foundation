# HUD: T002 - Introduce request-scoped trust evaluation and fast-path freshness helpers in `scripts/read_code_health.py`

## Objective

Deliver `T002` so the read preflight path can make a request-scoped trust decision instead of treating every `read_code context` lookup like a broad repo-wide freshness check.

This task establishes the health-side contract that later routing tasks will use to skip the heavyweight vector status probe for trusted scoped reads while preserving the current hard failure for genuinely unavailable or missing index states.

## Relevant Domains

- `Code Reading and Discovery`: this task changes how read preflight decides whether vector freshness must be proven synchronously for the current request.
- `Resilience`: the new fast path must still reject missing or unusable vector state and keep the existing error surface predictable.
- `Reuse at Every Scale`: centralize trust evaluation in `scripts/read_code_health.py` so `read_code.py` does not duplicate cache, freshness, or stale-state logic.
- `Test Driven Verification First`: later tasks depend on this contract, so the trust decision needs explicit unit coverage around healthy, stale, missing, and unavailable outcomes.

## Candidate Design Slices

- `Slice PL-01 - Scoped Trust Fast Path` — avoid global vector freshness proof by default for scoped requests while preserving seam selection. Primary seams: `scripts/read_code_health.py:_refresh_indexes_for_read` and `scripts/read_code_health.py:vector_refresh_by_state`.
- `Slice PL-03 - Benchmark and Regression Coverage` — this task defines the trust contract that later regression coverage will exercise for healthy, stale, and missing states. Supporting seam: `scripts/read_code_health.py:vector_index_probe`.

## Proposed Solution

- Add a request-scoped trust evaluator in `scripts/read_code_health.py` that can answer whether a scoped read may trust the current session or scope-local state without forcing a fresh global `vector_index_probe(...)` on every call.
- Refactor `_refresh_indexes_for_read(...)` so it consumes a scoped trust decision instead of unconditionally calling `vector_refresh_by_state(file_path, verbose=verbose)` for every repo-local read.
- Keep the existing hard-gate behavior for `missing`, `unavailable`, and `probe-failed` states, but split the healthy-session/scoped-fast-path case from the broad or unknown case.
- Change the following symbols in this task: `scripts/read_code_health.py:_refresh_indexes_for_read`, `scripts/read_code_health.py:vector_refresh_by_state`, and a new helper such as `scripts/read_code_health.py:evaluate_read_vector_trust` or equivalent.

## Current Repo Behavior

- `_refresh_indexes_for_read(...)` currently returns early only for non-repo-local paths, then always calls `_ensure_codegraph_session_available(file_path)` and `vector_refresh_by_state(file_path, verbose=verbose)`.
- `vector_refresh_by_state(...)` always starts by calling `vector_index_probe(REPO_ROOT)`, even for a known file-scoped read.
- `vector_index_probe(...)` first checks the session cache, but on a miss it shells out to the indexer `status` command and parses the full freshness payload before any scope-local overlap logic runs.
- The current preflight contract therefore proves repo-wide vector freshness first and only computes scoped overlap after the expensive global probe has already been paid.

## Target Behavior

- Preserve the story outcome for scoped reads: later tasks must be able to avoid repeated heavyweight freshness proof on exact path, exact symbol, and file-local requests.
- Preserve the story proof from `tasks.md`: scoped benchmark reads must still resolve the same seam and must still fail clearly when vector state is genuinely missing or unusable.
- Fulfill the `Slice PL-01` directive in task-local form by creating a trust decision that can distinguish trusted scoped reads from requests that still require the slower freshness path.
- At `scripts/read_code_health.py:_refresh_indexes_for_read`, make the preflight branch on request-scoped trust first, while keeping the current error contract for missing, unavailable, and probe-failed vector states.
